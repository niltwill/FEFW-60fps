# Fire Emblem: Fortune's Weave - 60 FPS

## Description

Forked this to add a pchtxt and IPS, so there's no need to use a cheat to get 60 FPS. Right now, this is for **version 1.10 (v131072)**. To get the NSOBID if it's not right for you (if this doesn't seem to work), you can use [hactool](https://github.com/alula/hactool) and edit it as required.

If a game update appears, this will stop working - but I'll try to update this if that happens. You can merge/include/use this however you need.

## Emulator recommendation

I'd recommend to use [Eglantine](https://github.com/Djihads80/Eglantine) for this game, or better yet, [Orchid](https://github.com/MythosOfs/Orchid) seems to work best for it... for now. At least in my initial few minute test runs (after starting the game to test the 60 FPS). If you happen to have a Mac, [nxnative](https://github.com/seedds/nxnative) could be more interesting to try though.

## How to use

Once you have the game in place, right-click on its title > `Open Mod Data Location`. This is where you can copy one of the folders into, depending on whether you prefer IPS or pchtxt (both works). Just copy only the `60 FPS` folder from either one of those folders to that location. Then make sure the mod is enabled, right-click on title > `Configure game`, at the first tab called *Add-Ons*, it should be ticked on automatically.
