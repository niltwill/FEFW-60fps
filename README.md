# Fire Emblem: Fortune's Weave - 60 FPS

## Description

Forked this to add a pchtxt and IPS, and the cheat also slightly changed. Right now, this is for **version 1.10 (v131072)**.

To get the NSOBID if it's not right for you (if this doesn't seem to work), you can use [hactool](https://github.com/alula/hactool) and edit it as required.

If a game update appears, it will probably stop working - but I'll try to update this if that happens. You can merge/include/use this however you need.

## How to use

Once you have the game in place, right-click on its title > `Open Mod Data Location`. This is where you can copy one of the folders into, depending on whether you prefer to use the cheat, IPS or pchtxt. Just copy only the `60 FPS` folder from either one of those folders to that location. Then make sure the mod is enabled, right-click on title > `Configure game`, at the first tab called *Add-Ons*, it should be ticked on automatically.
